# Research process archive

Per-round working papers, kept public on purpose: conclusions in `docs/` must
be traceable back to the round that produced them.

- `round1/` — Round 1 industry scan working papers:
  A open-source discovery · B commercial SaaS · C isolation principles · D threat model & benchmark design
- `round2/` — Round 2: evidence-debt clearance notes + OpenSandbox source-level deep dive work log
  (final deep-dive report lands in `docs/`)

Grades inside working papers follow the same A/B/C/U discipline as the main
documents; a claim graduates into `docs/` only after cross-verification.
