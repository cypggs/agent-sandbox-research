| ID | 冻结通过线 | 备注 |
|---|---|---|

## 2. 统计口径（沿 D 线设计，冻结确认）

nearest-rank 分位数；n<100 只报 P50 与 max；100≤n<300 报至 P95；n≥300 报 P99；
延迟必报五元组 (n, P50, P95, P99, max) + 失败数/失败率（不满足样本门槛的分位写 N/A 并注明 n）；
失败样本不进分位但必入失败率且不重试掩盖；异常值不删除；同条件 ≥3 批并报批间波动；
差异小于批间波动时结论写「当前测量精度下不可区分」。

## 4. 标准任务套件 ST v1.0（冻结规格）

- ST-1 空任务：创建环境 → 运行探针（输出固定字符串+自身资源视图）→ 销毁；成功判据：探针输出匹配 + C7 清单全清。LAB-MINI 以「namespace+cgroup 隔离单元」为环境载体，载体差异须在报告声明。
- ST-2 纯计算：固定 Python 脚本（SHA-256 迭代 1,000,000 次 + 斐波那契递归基准段），脚本哈希登记；成功判据：输出哈希与基准值一致。
- ST-3 工具链：规格冻结（固定小项目 pip 安装 + pytest），**LAB-MINI 延后**：依赖源镜像化未就绪、且本层无容器运行时，状态记「冻结-待 LAB-REF/镜像就绪」。
- ST-4 文件密集：生成 1,000 个 × 4 KiB 文件 → 全量读回校验 → tar 打包；成功判据：打包文件 SHA-256 与清单一致。
- ST-5 网络：仅访问自有哨兵服务的固定请求集（与 C8 矩阵共用哨兵）；成功判据：allow 全通、deny 全拒。
- ST-6 浏览器：子轨冻结定义，LAB-MINI 无浏览器环境，延后。
